# 网申助手 · 智能填充（Edge 插件）

基于个人资料 Markdown 文档自动填充网申表单，本地关键词匹配优先，LLM 语义匹配兜底，并能为开放性问题（自我评价、职业规划等）生成回答。

## 安装（Edge）

1. 打开 Edge，地址栏输入 `edge://extensions/`
2. 打开左下角「开发人员模式」
3. 点击「加载解压缩的扩展」，选择本文件夹（`wangshen-autofill`）
4. 浏览器工具栏出现插件图标即安装成功

## 使用步骤

1. **导入资料**：右键插件图标 →「选项」（或点击弹窗里的「⚙️ 资料与 API 设置」），把你的 MD 资料粘贴进「① 个人资料」，点击「保存资料」。可先点「填入模板示例」或参考 `profile-template.md` 的格式。
2. **（可选）配置 LLM**：在「② LLM 配置」勾选启用，填入 OpenAI 兼容接口的 Base URL、API Key、模型名，点「测试连接」验证。
3. **（可选）粘贴 JD**：在「③ 目标岗位 JD」粘贴职位描述，LLM 生成开放题答案时会向 JD 靠拢。
4. **填充**：打开网申页面 → 点插件图标：
   - 「⚡ 快速填充」：仅本地词典匹配，零成本、秒级完成
   - 「🤖 智能填充」：本地匹配 + LLM 兜底 + 开放题生成

## 颜色反馈

- 🟢 绿色边框：本地匹配填充
- 🟣 紫色边框：LLM 生成填充
- 🟡 黄色边框：未识别，需人工填写

## 隐私

- 个人资料、API Key 均仅存于本机浏览器 `chrome.storage.local`
- 仅在点击「智能填充」时，由后台页面向你配置的 LLM 接口发送「资料 + 未匹配字段标签」
- 插件不会主动覆盖已填写的字段

## 文件结构

| 文件 | 作用 |
|---|---|
| `manifest.json` | 插件清单（MV3） |
| `popup.html/js` | 弹窗：触发填充、显示状态 |
| `options.html/js` | 设置页：资料导入、LLM 配置、JD |
| `profile-parser.js` | MD 资料解析器（设置页与内容脚本共用） |
| `content.js` | 表单扫描、标签提取、本地匹配、填充与高亮 |
| `background.js` | LLM 请求代理（避免 CORS、保护 Key） |
| `profile-template.md` | 资料填写模板 |

## 已知限制

- 下拉框使用模糊匹配选项文本，个别复杂级联下拉（省市区联动）可能需要人工选择
- 富文本编辑器（如某些网申用的 wangEditor/UEditor）目前按普通 textarea 处理，个别站点可能需要手动粘贴
- 文件上传（简历、证件照）无法自动处理
